# Duplicate Finder 2.0

بازنویسی ماژولار برنامه تشخیص فایل تکراری برای ویندوز.

## اولویت نگه‌داری

1. `Keep` — محافظت مطلق؛ فایل‌های داخل آن هرگز انتخاب یا منتقل نمی‌شوند.
2. `PriorityFolder 1`

5. سایر پوشه‌ها

اگر یک فایل یکسان در `Keep` و هر مسیر دیگری وجود داشته باشد، نسخه داخل `Keep` حفظ و تمام نسخه‌های بیرون آن پیشنهاد حذف می‌شوند.

## امکانات

- گروه‌بندی اولیه براساس اندازه
- هش سریع ابتدا و انتهای فایل
- هش کامل فقط برای کاندیدها
- کش SQLite برای اسکن‌های بعدی
- پردازش هم‌زمان و توقف واقعی
- تشخیص نام‌های مشابه
- انتقال امن به `backup_deleted`
- Undo برای آخرین انتقال
- رابط کاربری بدون قفل‌شدن
- تنظیمات ماندگار

## اجرا

